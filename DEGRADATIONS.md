# Public capability limitations

This public source bootstrap is licensed under Apache-2.0. It is not a signed production release.

- OCR is unavailable with explicit OCR_NOT_INCLUDED_PENDING_MODEL_RIGHTS. A rights-verified engine and models plus accuracy tests are required for restoration.
- Exact private Word/Excel forms and their images/layout are replaced by generic synthetic templates; private form fidelity is not promised. A newly authored public form and export/render verification are required.
- Real catalogues, private alias/price mappings and original demo/customer profiles are absent. Only independent synthetic examples and external local data contracts are supplied.
- Production cloud, updater/deployment configuration, signing/install continuity and account-specific health are excluded. Offline is the default; public adapter contracts do not grant production access.
- Android source builds as an unsigned publicValidation test variant with 44 JVM tests. Actual install, upgrade, OEM storage grants and document saving remain separate device checks. Prior production release lint did not complete; no production release validation is claimed.
- Local coverage includes 78 Web tests, 24 baseline browser checks, 24 Activity checks and 25 draft-recovery checks. This supports declared generic capabilities, not every private integration or device environment. Hosted CI has not run.
- CREATE editing drafts have no formal Activity identity. Durable acknowledgment is required for successful saves. Unsupported/corrupt drafts require explicit recovery handling. Unacknowledged writes, browser quota, external backup and old-client downgrade remain limitations.
- An unrelated historical first browser failure was not reproduced; its root cause remains unknown.

Missing values stay unknown; uncertain identity is not silently promoted. See DECLARED-PUBLIC-VARIANTS.md for responsibilities and coverage.
