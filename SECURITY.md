# Security

Do not post credentials, business data, real screenshots or private logs in public issues or pull requests. Supply a synthetic reproduction without personal information. Do not use any discovered credential to test access.

This project has no designated reporting email or guaranteed response SLA. Use GitHub private vulnerability reporting if enabled; if unavailable, request a private reporting channel without disclosing details publicly. No enabled channel is claimed here.

This is local-first development software. Browser storage is not a substitute for backup. OCR, production cloud services, signing and auto-update infrastructure are excluded. Device and OEM permissions need independent validation. Dependency installation uses public networks; do not install unknown attachments or submit local data to external diagnostic services.
