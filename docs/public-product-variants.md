# Declared public variants

| Area | Public substitute | Functional limit | Core truth |
| --- | --- | --- | --- |
| Real business data and mappings | Independently invented customers, hospitals, employees, sales and activities | No real operational history or real-directory completeness claim | Stable identity, scope, missing-data and lifecycle contracts preserved |
| Private Office forms | Generic independently authored document fixtures and exporters | No original business-form or native Office rendering fidelity claim | Observed amounts and unknown/zero distinctions preserved |
| Production signing | Unsigned publicValidation Android build | No trusted production install or update channel | Shared Web and JVM contracts preserved |
| Production updater | Source build and manual evaluation | No automatic production updates | No product-data inference or identity change |
| Private deployment and cloud adapters | Public-safe local configuration and adapters | No private cloud deployment or production credentials | Local persistence and acknowledgement limits remain explicit |
| OEM and device distribution | Chromium, unsigned build, shared JVM checks | Actual WebView/IME/SAF/OEM/upgrade and URI readback remain separate | No emulator or real-device PASS claim |
| External/private backup infrastructure | Local generic backup/restore | External durability needs independent backup and readback | Corrupt/unknown state is not invented as valid data |

These variants are acceptable for a declared public product candidate. They do not authorize production release, npm publication, private data publication or canonical cutover.
