# Contributing

First-party contributions are accepted under Apache-2.0. Submit only work you own or are authorized to contribute, and preserve applicable third-party notices. No separate CLA is established here.

Use invented fixtures and focused regression tests. Preserve Missing ≠ 0, uncertain identity, explicit confirmation, separate Task/Activity lifecycle and durable-acknowledgment behavior. Do not silently change persistence schemas, API guarantees or compatibility. Review public variants before proposing integrations. Run the README checks; distinguish tests run from tests not run.

Never contribute real people, hospitals, sales, business mappings, private forms, signing files, production URLs, secrets, internal evidence or Git history from private sources. Check dependency licenses and include required notices. Avoid raw data in bug reports.
